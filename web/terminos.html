2. El servicio

La demo permite probar el reconocimiento de palma de Palmyn: registrás tu palma con la cámara y después comprobás si el sistema la reconoce. Es gratuita y con fines de demostración y prueba.

El resultado ("coincide" o "no coincide") es experimental. No sirve para identificarte, autenticarte ni acreditar nada ante terceros, y no debe usarse para tomar decisiones sobre personas.

3. Quién puede usarla

Para usar la demo tenés que:

  • ser mayor de 18 años;
  • usar únicamente tu propia mano;
  • no residir en Illinois, Texas ni Washington (EE.UU.);
  • aceptar cada una de las declaraciones del consentimiento antes de abrir la cámara.

4. Uso permitido

Podés usar la demo de forma personal y razonable. No está permitido:

  • capturar la mano de otra persona, o fotos, videos, réplicas o modelos de una mano;
  • usar programas, bots o scripts para enviar pedidos, o eludir los límites de intentos o las restricciones geográficas (por ejemplo con VPN);
  • intentar extraer, copiar o reconstruir el modelo, los tokens de otras personas o las plantillas;
  • probar la seguridad del servicio, saturarlo o interferir con su funcionamiento sin nuestra autorización por escrito;
  • usarlo para cualquier fin ilegal o que afecte derechos de terceros.

Si encontrás una falla de seguridad, te pedimos que nos la informes a la dirección de la sección 11 en lugar de aprovecharla.

Podemos bloquear el acceso a quien no cumpla estos términos.

5. Tu token

Al enrolar, tu navegador guarda un token cifrado con tu plantilla. Vos sos responsable de conservarlo: si lo borrás o cambiás de navegador o dispositivo, se pierde y tenés que enrolar de nuevo. El token vence a los 90 días y puede dejar de funcionar antes si actualizamos el modelo o las claves de cifrado.
